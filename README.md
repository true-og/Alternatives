# Alternatives

![Icon](https://git.trueog.net/trueog/website/raw/branch/main/assets/images/logos/Logo-Alternate-Transparent.png)

*ad astra per aspera*

Alternative plugin implementations tracked by TrueOG Network for evaluation, compatibility, or use
when the primary suite choice is unsuitable.

Each component remains an independent Gitea repository and is pinned here as a submodule:

- [advanced-region-market](https://git.trueog.net/trueog/advanced-region-market)
- [PureKitPvP](https://git.trueog.net/trueog/PureKitPvP)
- [MiniMOTD](https://git.trueog.net/trueog/MiniMOTD)
- [QuickShop-OG-Alt](https://git.trueog.net/trueog/QuickShop-OG-Alt)

See each individual submodule for its license and attribution.
